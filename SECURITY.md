# Security Policy

## Supported versions

NyxD is pre-release software. Security fixes are currently applied only to the latest revision of the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability that could expose diary content, passwords, encryption keys, or backup data.

Use GitHub's private vulnerability reporting feature for this repository. Include the affected revision, impact, reproducible steps, relevant device and toolchain versions, and any suggested mitigation.

Never include real diary content, passwords, keys, or databases in a report. Use generated test data only.

The project is not professionally audited. A response timeline cannot be guaranteed while it is maintained on a best-effort basis.
