Полный доступный автоматический прогон завершён успешно. Ошибок статического анализа, unit/widget-тестов, Android integration-тестов и сборки APK не обнаружено.

## Проверка release APK

- Package: `dev.nyxd.nyxd`.
- Версия: `0.0.1`, versionCode `3`.
- minSdk: Android API 24.
- targetSdk: Android API 36.
- Архитектуры: `armeabi-v7a`, `arm64-v8a`, `x86_64`.
- `android:allowBackup="false"` присутствует.
- Подключены `fullBackupContent` и `dataExtractionRules`.
- База, файлы, настройки и внешние файлы исключены из cloud backup и переноса между устройствами.
- Release-манифест не содержит флага `debuggable`.
- В исходниках приложения не обнаружены вызовы `print`, `debugPrint` или другого прикладного логирования секретов.

## Артефакты

- Debug APK: `build/app/outputs/flutter-apk/app-debug.apk`.
- Release APK: `build/app/outputs/flutter-apk/app-release.apk`.

## Что нельзя подтвердить этим прогоном

- Производительность Argon2id на слабом и среднем реальном телефоне.
- Фактическое скрытие содержимого в списке недавних приложений на конкретной прошивке.
- Полный пользовательский сценарий системных диалогов импорта и экспорта не автоматизирован; он принят вручную на эмуляторе.
- Сравнение Argon2id с независимым официальным тестовым вектором пока не добавлено: текущий тест проверяет NFKC, детерминированность и длину ключа, а Android integration-тест — совместимость полученного ключа с SQLCipher.

## Наблюдения

- Flutter сообщил о десяти более новых версиях транзитивных зависимостей, несовместимых с текущими ограничениями. Это не ошибка сборки. Обновление зависимостей следует проводить отдельной задачей с повторным полным прогоном.
- Gradle/JDK вывел предупреждение о будущем ограничении native access. На текущей версии сборка проходит; перед будущим обновлением JDK или Gradle совместимость нужно проверить повторно.
